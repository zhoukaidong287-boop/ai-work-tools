# ai-work-tools

## 项目定位

`ai-work-tools` 是一套主动营销点将作战工具库，用于家装/整装门店在点将周期内做客户池复盘、CRM 跟进、抖音线索承接、AI 研判、日报输出、信息流素材测试和投流复盘。

当前项目是纯前端静态网页工具，主要部署在 GitHub Pages。数据主要保存在当前浏览器的 `localStorage` 中，不依赖后端数据库。修改代码时必须高度注意数据兼容，不能清空或破坏用户已有数据。

## 主要使用场景

- 欧派整装大家居门店
- 家装主动营销
- 21 天点将周期
- 销售客户池复盘
- 抖音本地生活/信息流线索承接
- 直播、短视频、信息流素材测试
- 每日复盘、日报、AI 研判

## 核心目标

- 提升签单转化
- 盘活客户池
- 承接前端线索
- 标准化跟进动作
- 建立每日数据复盘机制
- 降低现场老师重复统计成本
- 让 AI 辅助生成研判、日报、素材和下一步动作

## 当前工具模块

- CRM 客户台账
- 销售客户池复盘
- 抖音线索池
- AI 每日点将研判台
- 日报/周报工具
- 信息流素材矩阵
- 信息流 AI 调令
- 投流测试工具
- 客户跟进记录
- 死单管理
- 新客户/客户阶段拆分逻辑

## 重要提醒

- 当前主要数据源是 `localStorage`。
- 未经用户明确确认，不要清空 `localStorage`。
- 未经用户明确确认，不要删除客户、线索、日报、AI 研判或客户池复盘历史。
- 未经用户明确确认，Codex 不要默认 Commit / Push。
- 新增字段必须兼容旧数据，旧数据缺字段时不能报错。
